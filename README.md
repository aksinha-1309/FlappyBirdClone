# Flappy Bird 2D Game 🎮

A feature-packed Flappy Bird clone game built natively in **Kotlin** using Android Studio.

## 🌟 Key Features
- **Custom Graphics & Physics:** Built with custom Canvas rendering, frame-rate responsive touch physics, and dynamic obstacle generation.
- **Score Tracking:** Local high-score management using `SharedPreferences`.
- **Monetization:** Integrated Start.io SDK for ads.
